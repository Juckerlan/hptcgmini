Pocket TCG V1.32 — Deck Code Import / Export

Replace index.html and data/cards.json in your existing project.
Do not delete your cards/ folder or your browser local storage.

Deck Builder > Export Deck Code: copy a code for a complete, valid deck.
Deck Builder > Import Deck Code: paste code, validate, and save as a new deck.
Duplicate names receive (2), (3), etc. Existing decks remain unchanged.
Codes include deck name, Starting Ally, 30 main cards and 10 Lessons.
Tokens cannot be imported into decks.
